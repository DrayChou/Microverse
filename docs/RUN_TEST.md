由于系统中没有安装 Godot 命令行工具，请按照以下步骤手动运行测试：

## 📋 测试步骤

### 方法1: 使用 Godot 编辑器（推荐）

1. **打开 Godot 编辑器**
   ```bash
   # 如果你安装了 Godot，可以用这个命令打开
   open -a "Godot" /Users/dray/Code/Microverse/project.godot
   ```

2. **创建测试场景**
   - 在 Godot 编辑器中，点击"场景" → "新建场景"
   - 选择"Node"作为根节点
   - 将场景保存为 `TestScene.tscn`

3. **附加测试脚本**
   - 选择根节点
   - 在检查器中点击"附加脚本"
   - 选择 `test_configs.gd` 文件
   - 保存场景

4. **运行测试**
   - 按 F5 或点击"播放"按钮
   - 查看编辑器底部的控制台输出

### 方法2: 快速验证

1. **创建验证场景**
   - 新建场景，选择"Node"
   - 附加 `validate_configs.gd` 脚本
   - 保存场景并运行

## 🔧 如果遇到错误

### 常见问题和解决方案：

1. **"❌ ContentManager初始化失败"**
   - 检查 `script/config/ContentManager.gd` 是否有语法错误
   - 确认所有依赖类都已正确加载

2. **"❌ 配置文件加载失败"**
   - 检查对应的 YAML 文件路径
   - 确认 YAML 语法正确（2个空格缩进）

3. **"❌ APIConfig初始化失败"**
   - 检查 `script/ai/APIConfig.gd` 语法
   - 确认 ContentManager 正常工作

4. **解析错误 (Parse Error)**
   - 检查控制台的具体错误信息
   - 确认文件路径和语法正确
